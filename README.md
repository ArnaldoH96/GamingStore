# Alpha Gear — Premium Gaming E-Commerce Store

An elegant, high-performance, mobile-first frontend storefront designed as a summative assessment for the **CPU4104-20C Web Development Module (Level 4)** at Bath Spa University / GBS.

## 🚀 Features

- **Responsive Mobile-First Design**: Uses custom CSS variables, CSS Flexbox, and CSS Grid without external frameworks.
- **Dynamic DOM Shopping Cart**: Multi-page persistence powered by lightweight local storage sync routines.
- **Client-Side Filtering**: Interactive instant filtering across 4 product domains.
- **Single-Page Popups**: Dynamically loaded product specifications utilizing clean JS modals.
- **Advanced Validation Engines**: Standard inputs evaluated instantly with explicit accessibility error notifications.
